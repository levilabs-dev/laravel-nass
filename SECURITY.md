This package handles NASS gateway and Nass Wallet merchant credentials. Please report security issues responsibly.

## Supported Versions

| Version          | Supported |
| ---------------- | --------- |
| 1.x (and `main`) | Yes       |
| < 1.0            | No        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

### Preferred: GitHub private reporting

1. Open the [Security tab](https://github.com/levilabs-dev/laravel-nass/security) for this repository.
2. Click **Report a vulnerability**.

### Alternative: email

- **Levi Labs:** [hello@levilabs.dev](mailto:hello@levilabs.dev)
- **Nizam Omer:** [nizam@nizaamomer.com](mailto:nizam@nizaamomer.com)

Include `levilabs/laravel-nass` in the subject line.
